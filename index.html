Private operational backup utility

Afrispore Backups

Afrispore Backups is an administrator-operated application for protecting the environmental monitoring system used by Afrispore. It is intended for authorised operators, not public registration.

Setup in progress. Cloud backup is being configured and tested. This website provides application information; it does not indicate that any backup has completed.

Monitoring data

Database snapshots preserve sensor readings, production cycles and monitoring settings.

Recovery files

Application code and selected operational configuration support recovery after a system restore.

Private storage

The planned workflow encrypts recovery bundles locally before uploading them to the administrator’s Google Drive.

Why Google Drive access is requested

The application uses rclone and Google’s authorisation flow to create, list, verify, download and remove its own backup files. It requests the drive.file permission. The application is not intended to browse unrelated Drive documents or read Gmail messages.

Planned schedule and recovery

The agreed schedule is daily at 21:00 in Africa/Lusaka, with a target of 30 daily recovery points. Offline uploads and retention will be validated before unattended use. A full USB system image remains a separate recovery resource.

The public website contains no monitoring dashboard, uploaded backups or sign-in form. Google authorisation is initiated from the administrator’s backup setup.
